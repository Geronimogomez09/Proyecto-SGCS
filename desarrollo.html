Ciclo de vida de un software

El ciclo de vida de un software es el conjunto de procesos que se siguen para desarrollarlo y mantenerlo.

Análisis

Se identifican las necesidades del usuario y se define qué debe hacer el sistema.

Diseño

Se define cómo será el sistema, su estructura, interfaz y funcionamiento.

Desarrollo

Se programa el sistema siguiendo lo definido en las etapas anteriores.

Pruebas

Se verifica que el sistema funcione correctamente y se buscan errores.

Despliegue

El sistema se instala y se pone a disposición de los usuarios.

Mantenimiento

Se realizan correcciones, mejoras y actualizaciones del sistema.
